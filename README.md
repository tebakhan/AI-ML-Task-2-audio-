# Audio Integrity Validation

## Overview
This project validates incoming audio streams to ensure they are complete, supported, and free from corruption before further processing.

## Objective
The goal of this utility is to detect and handle invalid audio inputs, including:
- Corrupted audio files
- Unsupported audio formats
- Incomplete audio chunks
- Damaged audio streams

## Features
- Audio format validation
- Corruption detection
- Incomplete chunk identification
- Error handling for damaged streams
- Validation status reporting

## Supported Formats
- WAV
- MP3

## Project Structure
- Final code.py
- README.md
- Final Report.docx

## How It Works
1. Accepts an audio file or stream as input.
2. Checks whether the format is supported.
3. Verifies that the audio data is complete and readable.
4. Detects corruption or damaged stream segments.
5. Returns a validation result.
